🗝️ 링크모음 마스터 — 나만 보는 파일
============================================

■ 이게 뭔가요?
  전체 도구 목록이 담긴 "원본(마스터)"입니다.
  여기서 필요한 도구만 골라 → 공유용 HTML 파일을 만들어 보냅니다.

■ 어떻게 여나요?
  master.html 을 그냥 더블클릭하세요. (인터넷/서버 필요 없음)

■ 사용 순서
  1) 보낼 도구 체크  ("결과수집 되는 것만" 버튼도 있어요)
  2) 제목 입력 + (학생용이면) 내 결과수집 주소 붙여넣기
  3) [공유용 HTML 파일로 내보내기] → 파일 1개가 다운로드됨
  4) 그 파일을 카톡/메일로 보내거나, 새 저장소에 올려 배포

■ 중요
  · 이 저장소는 GitHub "비공개(private)" 입니다. Pages 배포도 하지 않습니다.
    → 절대 public 으로 바꾸거나 Pages 를 켜지 마세요. (켜면 전체 목록이 공개됨)
  · 내보낸 공유용 파일에는 "고른 도구만" 들어갑니다 → 전체 목록이 새지 않아요.

■ 백업 / 다른 컴퓨터에서 쓰기
  저장소: https://github.com/hongyul67-cpu/links-master  (비공개)
  · 수정했으면 저장:   git add -A ; git commit -m "수정" ; git push
  · 다른 PC에서 받기:  git clone https://github.com/hongyul67-cpu/links-master.git
    (또는 GitHub 웹에서 Code ▾ → Download ZIP)
  · 결과수집 주소를 넣으면 각 도구 링크에 자동으로 붙어 결과가 내 시트로 옵니다.
    - 학생에게 줄 때 → 주소 넣기
    - 다른 선생님께 줄 때 → 비워두기 (그분은 링크생성기로 자기 주소를 씀)

■ 기존 공개 허브는?
  https://hongyul67-cpu.github.io/links/  → 그대로 살아있습니다 (건드리지 않았어요).

■ 새 도구를 만들면
  master.html 안의 TOOLS 목록에 한 줄 추가하세요.
  (공개 허브 index.html 의 TOOLS 와 같은 형식입니다. 두 곳을 맞춰두면 좋아요.)
  rc:true 를 넣으면 "결과수집" 배지가 붙고 [결과수집 되는 것만] 선택에 포함됩니다.
