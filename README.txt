🗝️ 링크모음 마스터
============================================

■ 주소 (나만 알고 쓰세요)
  https://hongyul67-cpu.github.io/links-master/
  · 즐겨찾기 해두면 어느 기기서든 바로 씁니다.
  · 저장소는 public 이라 주소를 아는 사람은 볼 수 있어요. 링크를 공유하지 마세요.
  · 내 PC 파일로도 됩니다: master.html 더블클릭

■ 이게 뭔가요?
  전체 도구 목록이 담긴 "원본(마스터)"입니다.
  앞으로 새 도구는 여기 TOOLS 목록에 추가하세요. (마스터가 중심)
  여기서 필요한 도구만 골라 → 공유용 HTML 파일을 만들어 배포합니다.

■ 사용 순서
  1) 보낼 도구 체크   ("결과수집 되는 것만" 버튼도 있어요)
  2) 제목 입력
  3) 상황에 맞게:
     👩‍🎓 학생에게 줄 때
        · "내 결과수집 주소"에 내 exec URL 넣기
        · "받는 사람이 자기 시트 연결" 체크 해제
        → 결과가 전부 내 시트로 옵니다.
     🧑‍🏫 다른 선생님께 줄 때
        · "내 결과수집 주소"는 비워두기
        · "받는 사람이 자기 시트 연결" 체크 (기본 켜짐)
        → 그 선생님이 파일 안에서 [내 시트 연결]을 누르고 자기 exec 주소를
          넣으면, 그분 학생 결과가 그분 시트로 갑니다.
  4) 전달 방법 2가지
     📱 [링크 + QR 만들기]  ← 추천
        · 주소 하나 + QR 이미지가 나옵니다.
        · 학생은 QR만 스캔하면 바로 열려요. 따로 배포할 필요 없음.
        · 고른 도구 목록이 주소 안에 압축돼 담깁니다(전체 목록 노출 없음).
        · 도구가 많으면 주소가 길어져 QR이 빽빽해져요 → 8개 이하 권장.
     📄 [공유용 HTML 파일로 내보내기]
        · 파일 1개 다운로드 → 카톡/메일 첨부. 인터넷 없이도 열림.

■ 내보낸 파일이 하는 일
  · 고른 도구만 들어있음 (전체 목록 노출 없음)
  · "내 시트 연결" 패널 (켰을 때): 받는 사람이 자기 exec 주소를 넣으면
    모든 도구 링크에 ?rc= 가 붙어 그 사람 시트로 결과가 감. 브라우저에 저장됨(재방문 유지).
    주소 형식 검증 + [해제] + 설치 가이드 링크 포함.

■ 새 도구를 만들면
  master.html 안의 TOOLS 목록에 한 줄 추가 → 저장 → git push
  rc:true 를 넣으면 "결과수집" 배지가 붙고 [결과수집 되는 것만] 선택에 포함됩니다.
  (공개 허브 index.html 은 예전 그대로 살아있음 — 굳이 안 맞춰도 됩니다)

■ 수정 저장 / 다른 PC에서 받기
